# Final submission gate

Read the actual task artifact list before judging completeness. Preserve provided task/README files unchanged. Validate required filenames/paths, no secrets or external credentials, no forbidden output, no missing startup instructions, and no untracked required files. Check reproducible launch from fresh DB/environment, health endpoint and Dockerfile if required.

If a human-only written test follows, stop ALL AI usage at the boundary and require the participant to type personal answers. Before that phase, summarize architecture/decisions, evidence and limitations in `EXPLAINABILITY_NOTES.md` but never fabricate the human's actions or claim future exam compliance.

No Git Push or external task artifact upload. Do not run Computer Use, browser automation, screen automation, or prohibited monitoring bypass.
